Service changes

    Routes are computed in your browser with Dijkstra's algorithm (binary heap, O(E log V)) over a graph of 125 stations, with a 4-minute penalty for changing trains. Travel times are averaged from MBTA weekday schedules.

    Alerts: live from the MBTA V3 API every minute, plus alerts scraped from mbta.com by a GitHub Actions pipeline (—).
